SKILL 使用指南

把好用的工作流程，裝進你的 AI 助手

先從下方選擇需要的 Skill，再依使用方式點選卡片上的按鈕。

01
GEMINI

Gemini生成技能

點下方技能卡的「Gemini生成技能」，複製完整 SKILL.md 內容。貼到 Gemini 後，告訴它：「請依這份內容建立技能，先不要執行任務。」

02
AGENT

Agent安裝技能

點下方技能卡的「Agent安裝技能」，複製 GitHub 技能資料夾連結。貼到支援 Skill 的 Agent，請它安裝這個技能及必要的附屬檔案。

03
GITHUB

原始來源

點下方技能卡的「原始來源」，開啟 GitHub 原始專案。可查看 README、SKILL.md 與附屬檔案，了解技能用途和所需工具。

04
PROMPT

複製原始prompt

點下方技能卡的「複製原始prompt」，複製提示詞全文，方便直接使用或自行修改。未附原稿的技能提供方方老師補寫版本，複製後會在下方備註。

使用提醒：複製後，請在你的 AI 助手中確認技能已建立或安裝完成。各技能需要的工具與附件，請參考「原始來源」。
