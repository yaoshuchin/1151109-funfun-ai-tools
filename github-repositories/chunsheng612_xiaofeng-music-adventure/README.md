# 小風的音樂冒險

互動音樂繪本，包含 13 頁插圖與 5 段音樂，支援翻頁、播放及停止音樂。

## 線上閱讀

https://chunsheng612.github.io/xiaofeng-music-adventure/

## 開啟方式

下載此儲存庫後，使用瀏覽器開啟 `index.html`。請將網頁、圖片和音檔放在同一個資料夾。

## 檔案

- `index.html`：GitHub Pages 網站首頁。
- `ai_studio_code.html`：原始互動繪本網頁。
- `0.png` 至 `12.png`：依序排列的 13 頁插圖。
- `4.mp3` 至 `8.mp3`：繪本第 4 至第 8 頁使用的音樂。

點選頁面或「下一頁」可翻至下一頁；點選「上一頁」可返回。音樂按鈕可播放或停止音樂，翻頁時會停止播放。
