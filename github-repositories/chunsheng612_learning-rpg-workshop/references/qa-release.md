# 測試與交付

## 本機閘門

先讀 `package.json` 找可執行檢查；不要對新作盲跑 Avalon 專用驗證器。原系列參考指令：

```bash
npm run typecheck
npm run verify:assets
npm run verify:questions
npm run verify:avalon
npm run verify:duel-audio
npm run build
```

新作建立對應檢查，不照抄固定敵人數、能力數、特定字串或絕對路徑斷言。優先測真正可能錯的規則，不用測試鏡像實作。

涵蓋：題目答案與唯一性、章節題池、關卡參照、素材存在、ready 素材足夠支援關卡、無效技能不扣 MP、勝敗優先序、重答與替換、獎勵一次性、存檔讀回。

## 玩家視角驗收

有瀏覽器工具時實際操作並留截圖和問題紀錄。參考尺寸：360×800、390×844、768×1024、1280×900。小修只跑相關分支與必要回歸。

| 情境 | 可觀察結果 |
|---|---|
| 首次進入 | 知道下一步，一個清楚主按鈕可開始已解鎖目標 |
| 正確／錯誤答案 | 傷害、HP、MP、連擊與解析一致，連點不能重算 |
| 提早擊破／玩家倒下／題數耗盡 | 各按目前規則勝敗，不以答完假裝擊破 |
| 技能不可用 | 原因可見、資源不減；可用時數值真的變化 |
| 收服（若有） | 敵人與獲得角色同 ID；MP 不足可理解 |
| 長題／長選項 | 全文可讀、選項可點，必要狀態不被擠掉 |
| 圖片 404／慢網路 | 同身分替代，預載有上限，仍可玩 |
| 領獎／下一關 | 返回不漏領，重開不重複領 |
| 重新整理／離線 | 保存進度與設定，失去雲端不阻擋玩法 |
| 音樂／朗讀／靜音 | 不重疊，朗讀結束或錯誤可恢復 |
| 鍵盤／減少動態 | 可操作、焦點可見，必要資訊仍存在 |

沒有瀏覽器或聲音設備時明列未執行項目；型別與 build 通過不是玩家驗收通過。發現問題先定位原因，修後重驗相關流程。

## 封裝與部署

本機交付包括原始碼、lockfile、必要素材、`.env.example`（只有欄位）、啟動方法、企劃與進度。不把高解析母檔全部塞公開資產，不交付憑證、node_modules、快取或舊 build 當原始碼。

只要求準備／打包時停在已驗證產物；已要求發布時完成部署與線上檢查。原系列用 Cloudflare Workers Static Assets，按目前 wrangler 設定及官方文件操作。核對帳戶／Worker 和 Firebase（若有），不沿用舊名誤蓋正式站。

發布前記版本與回復點，更新 health／版本及 service worker cache。發布後查首頁、深層路由、主要圖片音檔、快取與至少一場戰鬥；health 200 不證明登入、同步或音訊正常。

雲端屬交付範圍時，測登入、本人資料、登出、跨裝置、離線與衝突。正式站出現阻斷問題時停止猜測部署，先定位；在授權內回復已知可用版本或說明阻礙。

報告列實際成果、題目／素材分階段數、已跑驗證、可開啟路徑／網址、剩餘項目；人工審稿與真人聽音未做就不算完成。
